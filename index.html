ProfileCard

A stats card for your
GitHub profile

Type a username. Get an SVG with your stars, repos, followers and top languages, in a theme you like. Drop it into your profile README.

Save the SVG in your username/username profile repo (for example card.svg), then paste the snippet into its README.

How it works

  1. It reads your public data from the GitHub API, in your browser. Nothing goes to our server, because there is none.
  2. Stars and languages count your own repos, not forks.
  3. The API allows 60 requests an hour per IP without a token, which is plenty for this.
