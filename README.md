# ProfileCard

GitHub stats and skills card generator for your profile README.

**Live: https://mostaaafaomran-ctrl.github.io/profilecard/**

Enter a username, get an SVG card with stars, repos, followers and top languages in 5 themes.

## Features

- Stars, repos, followers, forks and top languages
- 5 themes: sunset, ocean, forest, mono, paper
- Download the SVG and copy the README snippet
- Reads the public GitHub API from your browser, no server, no token

## Run locally

No build step. Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```

## Privacy

Everything runs in your browser. Nothing is uploaded and there is no account.

## العربية

اكتب اسم المستخدم واطلع كارت SVG بإحصائيات حسابك على GitHub للـREADME.
